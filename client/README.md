# Wayfinders — Godot client

Godot 4.4 (.NET / C#) client. Steam target.

## Open

1. Install Godot 4.4 **.NET** build (https://godotengine.org/download).
2. Open Godot, click *Import*, select `client/project.godot`.
3. Press F5 — console prints `Hello Wayfinders`.

First open will trigger a `dotnet restore` and a build of `Wayfinders.csproj`.
